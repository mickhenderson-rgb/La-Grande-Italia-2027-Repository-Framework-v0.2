# La Grande Italia 2027
## The Henderson Grand Tour

Version: 1.0 Development Edition

---

# Project Overview

This repository contains the complete planning and operational guide for the Henderson Grand Tour through Italy and Switzerland.

The guide is being developed as a browser-based travel application rather than a traditional document.

Primary objectives:

- Fully searchable
- Offline capable
- Printable
- Mobile friendly
- Easy to update
- Designed for use before, during and after travel

# Content Philosophy

Every destination answers:

- Why are we here?
- How do we arrive?
- Where do we park?
- Where do we eat?
- What should we photograph?
- What should we book?
- What should we avoid?

The guide is intentionally practical.
