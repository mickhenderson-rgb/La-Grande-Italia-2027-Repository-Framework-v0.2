La Grande Italia 2027

Repository Guide

Open index.html in any browser. Keep the whole folder together so linked assets work.

How to use

  1. Open index.html directly in Chrome, Edge, Safari or Firefox.
  2. Edit pages in pages/ and shared styling in assets/css/style.css.
  3. Update data in data/ as bookings change.
  4. Zip the entire folder to share it as one repository.
