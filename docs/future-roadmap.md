# COMPASS-TOS

## Future Roadmap

This document contains ideas intentionally deferred from Version 1.

These items are not forgotten.

They are deliberately postponed to keep Version 1 simple and usable.

---

# Version 1 Goal

Create the best offline travel planning and travel journal application for family and friends.

Everything required to complete a trip must work without internet.

---

# Version 2 Goal

Enhance Version 1 with optional online services.

Internet should improve the experience.

It should never be required.
