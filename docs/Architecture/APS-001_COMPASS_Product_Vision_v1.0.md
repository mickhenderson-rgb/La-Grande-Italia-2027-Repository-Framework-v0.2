# APS-001 – COMPASS Product Vision

## Purpose
COMPASS-TOS is a personal Travel Operating System (Travel OS) for planning, travelling and recording journeys.

## Vision
Research → Compare → Decide → Book → Travel → Remember

## Design Goals
- Personal use
- Reliability over complexity
- HTML/CSS/Vanilla JavaScript
- JSON data
- Git version control
- Offline-first where practical

## Success Criteria
- Fast planning workflow
- Easy maintenance
- Readable code
- Incremental evolution
